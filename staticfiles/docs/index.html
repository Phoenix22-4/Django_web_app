AquaSavvy SOLUTION Documentation

Vision Technology — Smart Water Management System

Overview

AquaSavvy SOLUTION provides real-time monitoring of water tank levels and intelligent pump control. It helps reduce water wastage and protect pumps from dry-run and overfill scenarios.

Key Features

  • Real-time level monitoring (underground and overhead tanks)
  • Automated pump protection and control
  • Alerts and notifications for low/high levels
  • Cloud dashboard with secure access
  • AI assistant for explanations and guidance

Getting Started

  1. Deploy sensors and connect controller to the network.
  2. Configure device credentials in the server dashboard.
  3. Create a user account and login to view your dashboard.

AI Assistant Setup (Optional)

To enable AI chat powered by Google AI (Gemini):

  1. Obtain an API key from Google AI Studio.
  2. Set the environment variable GEMINI_API_KEY on your server.
  3. Configure the integration in your Django settings and views (see project README or integration module).
If AI chat is unavailable, users can still access all core AquaSavvy features. For urgent assistance, use the contacts below.

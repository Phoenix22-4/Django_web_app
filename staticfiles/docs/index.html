AquaSavvy Solution Documentation

Vision Technology — Smart Water Management System

Overview

AquaSavvy Solution provides real-time monitoring of water tank levels and intelligent pump control. It helps reduce water wastage and protect pumps from dry-run and overfill scenarios.

Quick Start Guide & User Manual

Welcome to AquaSavvy Solution! You now have a smart water management system that automatically protects your pump and lets you monitor your water levels from anywhere.

1. How to Use Your Web Dashboard

  • Login: Go to the provided link and log in with your credentials.
  • Device List: Select your device/property to monitor.
  • Monitor Your Tanks: View Underground and Overhead tank levels in real time.
  • Manual Pump Control: Use "PUMP ON" and "PUMP OFF" to control your pump.

2. Automatic Features

  • Automatic Pumping: Refills the Overhead Tank when low and turns off near full.
  • Dry-Run Protection: Prevents pump operation when Underground Tank is empty and shuts it down quickly to avoid damage.

3. Indicators

  • Green LED: System is powered and working.
  • Red LED: Pump is ON.
  • Local Display: Shows the same levels as the web app.

4. Power Cuts

If mains power is off, the controller stays on for hours with backup. The pump itself requires mains power.

5. Troubleshooting

  • If you can't see data, check Wi‑Fi and that the device has power (Green LED).
  • If the pump won't turn on, check Underground Tank level and your home's pump breaker.

Key Features

  • Real-time level monitoring (underground and overhead tanks)
  • Automated pump protection and control
  • Alerts and notifications for low/high levels
  • Cloud dashboard with secure access
  • AI assistant for explanations and guidance

Getting Started

  1. Deploy sensors and connect controller to the network.
  2. Configure device credentials in the server dashboard.
  3. Create a user account and login to view your dashboard.

AI Assistant Setup (Optional)

To enable AI chat powered by Google AI (Gemini):

  1. Obtain an API key from Google AI Studio.
  2. Set the environment variable GEMINI_API_KEY on your server.
  3. Configure the integration in your Django settings and views (see project README or integration module).
